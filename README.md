# customer-churn-powerBI
Customer Churn Analytics Dashboard built in Power BI analyzing churn drivers, customer segmentation, and revenue risk using DAX and interactive visuals
📊 Customer Churn Analytics Dashboard
This project analyzes customer churn behavior using Power BI to identify key drivers, segment high-risk customers, and quantify revenue at risk.

🎯 Business Objective
To understand why customers churn and identify actionable insights to reduce churn and improve retention strategies.

🧰 Tools & Technologies
Power BI

DAX

Power Query

Data Modeling

📈 Key Metrics
Total Customers

Churned Customers

Churn Rate

Revenue at Risk

ARPU

🔍 Key Insights
Customers on month-to-month contracts have highest churn

Majority churn occurs within first year

Fiber optic customers show higher churn probability

High-value customers contribute significant revenue risk
